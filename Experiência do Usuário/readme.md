# Experiência do Usuário
### ➤ Competências da disciplina
 ➥ Unidade 1: Aspectos sobre a Experiência de Usuário (UX) em Interfaces Digitais
  - Compreender aspectos fundamentais da experiência de usuário, necessários à construção de interfaces digitais, de forma abrangente.

 ➥ Unidade 2: Psicologia e UX
  - Compreender aspectos da psicologia que influenciam a experiência de usuário em produtos e serviços digitais, na interação humano-computador, de forma construtiva.

 ➥ Unidade 3: Processo de desenvolvimento de interfaces visando à UX
  - Aplicar o processo de desenvolvimento de interfaces visando à positiva experiência do usuário na interação humanocomputador, de forma construtiva.

 ➥ Unidade 4: Avaliação de Usabilidade
  - Analisar a usabilidade, característica de qualidade no desenvolvimento de software, de forma colaborativa.
