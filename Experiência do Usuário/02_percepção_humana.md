# Psicologia do Usuário e  Percepção Humana
- projeto de interfaces: experiência e expectativa do usuário
  - identificar/conhecer habilidades do usuário: física, perspectiva e cognitiva
- psicologia cognitiva estuda como a mente trabalha: como pensamos, como aprendemos, como lembramos
- sistema visual humano: exige uma pequena quantidade de tempo para reagir a estímulos e mover os olhos para onde a informação está sendo apresentada, as vezes é preciso ler e reler a mensagem para compreender
- sistema de percepção humana irá associar significado à informação recebida seja ou não o significado pretendido ou exato
  - reconhecimento por casamento de padrões ➜ experiência passada afeta o processamento de percepção
- no meio há muita informação, constante processamento ➜  qualquer mudança no ambiente atraem a atenção (luz, som, cor, novidades)
- uma imagem pode ser ambígua ➜  por falta de informação ou pelo excesso dela
  - a percepção auditiva sofre o mesmo processo
- a organização visual da informação pode resultar em ilusões ➜  percepção do espaço e de profundidade
- todos os dados sensoriais são usados para construir uma interpretação consistente do mundo visual
  - sistemas sensoriais exigem mudanças na estimulação para manter a percepção
    - audição ➜ não há constância
    - tato ➜ depois de algum tempo não percebemos
    - olfato ➜  um cheiro é notado menos por quem está usado
    - efeito posterior ➜  visão prolongada de uma imagem pode mudar a perspectiva
- interfaces gráficas ➜ o projetista deve estar consciente das possibilidades e restrições do usuário
  - oferecem facilidades ao usuário ➜ exigem processamento perceptivo intenso
  - transferem a memorização e a carga cognitiva das interfaces baseadas em linguagens de comando para o processamento perceptual e viso motor


# Modelo do Processamento de Informação Humano (MPIH)
- referência clássica para esse modelo são os trabalhos de Card, Moran e Newell (1983)
  - buscam entender o uso de interfaces em relação ao processamento motor, perceptual e cognitivo do sistema humano
- traz a noção de memória como tendo força e podendo fortalecer-se pela repetição
  - memória como um conjunto de chunks discretos na memória de longa duração  
- interação com computadores pode ser afetado pelo funcionamento de mecanismos perceptuais, motores e de memória
- MPIH é uma descrição aproximada para ajudar a prever a interação usuário-computador
- é composto por:
  - um conjunto de memórias e processadores e um conjunto de princípios de operações
  - 3 subsistemas:
    - sistema perceptual (SP)
      - PP ➜ Processador Perceptual
      - MIV ➜ Memória Imagem Visual
      - MIA ➜ Memória Imagem Auditiva
     - sistema motor (SM)
        - PM ➜ processador motor
    - sistema cognitivo (SC)
      - MCD/MT ➜ Memória de Trabalho ou Memória de Curta Duração
      - PC ➜ Processador Cognitivo
      - MLD ➜ Memória de Longa Duração
